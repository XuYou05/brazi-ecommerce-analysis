\# 巴西 Olist 电商数据分析



基于 Olist 公开数据集的电商数据分析项目。



\## 项目内容



\- 热销品类分析

\- 各州订单分布

\- 配送时间统计

\- 延迟与评分关系

\- 卖家评分与配送时间

\- 复购率分析



\## 分析结论



1\. 床品、美妆、运动是平台最热销的三大品类

2\. SP 州订单占比约 42%，电商高度集中

3\. 平均配送时间约 12 天，延迟率约 8%

4\. 延迟送达会显著拉低客户评分

5\. 平台复购率仅约 3%，是核心问题之一



\## 技术栈



\- Python
